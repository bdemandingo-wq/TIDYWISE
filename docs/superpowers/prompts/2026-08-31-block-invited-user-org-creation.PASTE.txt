   ```json
   { "skipped": true, "reason": "pending_team_invite" | "accepted_team_invite", "invite_organization_id": "<id>" }
   ```
   Do NOT create an organization.

4. Only if there is no membership AND no blocking invite, create the trial organization with `needs_onboarding = true` and an owner membership.

=== DATABASE: PREVENT STRAY `organizations` INSERTS AT THE POLICY LEVEL ===

Create or replace a helper function and update the INSERT policy on `public.organizations` so that even a direct API call cannot create a business for an invited account.

Migration SQL:

```sql
-- Helper: is this user allowed to create a brand-new organization right now?
CREATE OR REPLACE FUNCTION public.current_user_may_create_organization()
RETURNS boolean
LANGUAGE sql
STABLE
SECURITY DEFINER
SET search_path = public
AS $$
  SELECT
    -- already a member somewhere -> no new business
    NOT EXISTS (
      SELECT 1 FROM public.org_memberships
      WHERE user_id = auth.uid()
    )
    AND
    -- has a pending valid invite or accepted invite -> no new business
    NOT EXISTS (
      SELECT 1 FROM public.organization_invites
      WHERE email = (SELECT email FROM auth.users WHERE id = auth.uid())
        AND (
          (accepted_at IS NULL AND expires_at > now())
          OR (accepted_at IS NOT NULL AND accepted_by = auth.uid())
        )
    );
$$;

-- Only the owner of the row being inserted, who also passes the helper, may insert.
-- service_role remains unrestricted for legitimate backend/admin provisioning.
DROP POLICY IF EXISTS "Users can create organizations" ON public.organizations;
CREATE POLICY "Users can create organizations"
ON public.organizations FOR INSERT
TO authenticated
WITH CHECK (
  auth.uid() = owner_id
  AND public.current_user_may_create_organization()
);

GRANT EXECUTE ON FUNCTION public.current_user_may_create_organization() TO authenticated;
```

Note: `public.current_user_may_create_organization()` is SECURITY DEFINER and reads `auth.users.email`. It must be granted only to `authenticated`; do NOT grant it to `anon`.
